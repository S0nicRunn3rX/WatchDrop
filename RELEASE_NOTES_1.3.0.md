# WearDrop 1.3.0

- Новое название WearDrop во всём интерфейсе.
- Подписанный release APK без суффикса `debug`.
- Сохранены множественная передача, встроенный файловый менеджер, уведомления прогресса и Material You.
- Для встроенного файлового менеджера добавлена точная ADB-команда выдачи `MANAGE_EXTERNAL_STORAGE`.

> Из-за перехода с тестовой debug-подписи на постоянную release-подпись предыдущую версию может потребоваться удалить один раз перед установкой.
